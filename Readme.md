# 🌿 小娜花园 · carina-garden

> 一个温柔、植物系的个人小窝。
> 读书、写作、运动、待办与专注，都种在这里。

小娜花园不是效率工具，也没有打卡压力。它只希望每一次打开时，
都让人感觉可以慢一点、轻一点。

纯静态、零构建、零后端。所有数据只保存在你自己的浏览器里，
不上传、不追踪、不联网。

---

## ✨ 功能一览

| 页面 | 做什么 |
| --- | --- |
| 🏡 首页 | Bento 总览：伍尔夫每日一句、今日摘要、时间进度、各模块入口 |
| 📖 读书 | 正在读的书、阅读进度、最近 28 天阅读日历、读过的书 |
| ✍️ 写作 | 今日字数、连续写作天数、灵感碎片墙 |
| 🏃 运动 | 运动打卡（散步 / 跑步 / 拉伸 / 力量）、连续天数、14 天视图 |
| ✅ 待办 | 三栏看板（待做 / 在做 / 完成），支持拖拽 |
| 🎯 目标 | 年度 / 季度 / 月度目标，环形进度，每次 +10% |
| ⏱️ 专注 | 独立番茄钟页面，环形倒计时，25 分钟一轮 |
| 🌤️ 天气 | 天气状态切换，花园边框随之联动 |
| 🌱 关于 | 花园说明、原则与更新日志 |

其他细节：

- 🌙 **主题切换**：浅色 / 深色，首次访问跟随系统偏好，之后记住你的选择
- 🐕 **柴柴助理**：本地运行的轻量助手，不调用任何 API
- 📱 **移动端**：底部标签栏，单手可达
- 🚀 **跨页过渡**：原生 View Transitions，零 JS 字节
- 🎞️ **滚动揭示**：CSS 滚动驱动动画，运行在合成线程
- 📲 **PWA**：可安装，可离线访问
- ♿ **可访问性**：skip link、`aria` 状态、`prefers-reduced-motion` 支持

## 🚀 部署到 GitHub Pages

### 方式一：从仓库直接部署（推荐）

1. 把整个项目推到 GitHub 仓库，分支为 `main`。
2. 进入仓库 **Settings → Pages**。
3. **Source** 选择 `Deploy from a branch`。
4. **Branch** 选择 `main`，目录选择 `/ (root)`，保存。
